# BONUS — LE KIT CV PRO

## Tous les outils dont tu as besoin pour tes prochaines candidatures

> Avant d'utiliser un prompt, anonymise ton CV et l'offre : enlève coordonnées, identifiants et informations confidentielles. Remplace-les par des marqueurs, puis vérifie toute réponse de l'IA et ne conserve que les faits exacts.

Tu as maintenant appris à construire un CV professionnel depuis ton téléphone.

Mais lorsque tu commenceras à envoyer régulièrement des candidatures, tu te rendras compte d'une chose :

> **Tu ne dois pas recommencer tout le travail depuis zéro à chaque candidature.**

Le plus intelligent est de créer ton propre **Kit CV Pro**.

Ce kit regroupe les modèles, prompts, messages et outils dont tu auras besoin pour préparer rapidement tes prochaines candidatures.

L'objectif est simple :

**Une fois ton kit préparé, chaque nouvelle candidature devient beaucoup plus rapide.**

---

# 1. Ton dossier principal

Commence par créer un dossier sur ton téléphone :

```text
KIT CV PRO
```

À l'intérieur, crée :

```text
KIT CV PRO
│
├── CV
├── MESSAGES
├── PROMPTS CHATGPT
├── LETTRES
├── OFFRES
└── SUIVI
```

Tu peux adapter cette organisation selon ton téléphone.

---

# 2. Ton CV principal

Dans le dossier **CV**, conserve toujours une version modifiable.

Par exemple :

```text
CV_MASTER.docx
```

Cette version contient toutes tes informations.

Elle peut être plus complète que le CV que tu envoies.

Elle sert de base pour créer tes différentes versions.

---

# 3. Tes différentes versions de CV

Si tu recherches plusieurs types de postes, crée des versions adaptées.

Par exemple :

```text
CV_Developpeur_Web.pdf
CV_Technicien_Informatique.pdf
CV_Graphiste.pdf
CV_Assistant.pdf
```

Tu n'es pas obligé d'en avoir beaucoup.

Commence avec les deux ou trois catégories de postes que tu recherches réellement.

---

# 4. Ton modèle de profil professionnel

Conserve également un modèle de base.

```text
[POSTE OU DOMAINE]

[TON TITRE / NIVEAU]

[TON PROFIL EN 3 À 5 LIGNES]

[PRINCIPALES COMPÉTENCES]

[TYPE D'OPPORTUNITÉ RECHERCHÉE]
```

Lorsque tu trouves une nouvelle offre, tu peux adapter ce modèle.

---

# 5. Ton modèle de compétences

Conserve une liste complète de toutes tes compétences réelles.

Exemple :

```text
COMPÉTENCES TECHNIQUES

- HTML
- CSS
- JavaScript
- React
- Git
- WordPress

OUTILS

- VS Code
- GitHub
- Photoshop
- Illustrator

COMPÉTENCES PROFESSIONNELLES

- Communication
- Organisation
- Travail en équipe
- Gestion de projet
```

Cette liste est ton **réservoir de compétences**.

Pour chaque candidature, tu sélectionnes uniquement les compétences pertinentes.

---

# 6. Ton inventaire d'expériences

Fais également une liste de toutes tes expériences.

Même les petites expériences peuvent être utiles.

```text
EXPÉRIENCES

- Stage
- Projet scolaire
- Projet personnel
- Freelance
- Mission ponctuelle
- Bénévolat
- Projet associatif
- Activité entrepreneuriale
```

```text
Nom :
Entreprise / contexte :
Date :
Rôle :
Missions :
Outils utilisés :
Résultats :
```

Cela te permettra de ne jamais oublier une expérience intéressante.

# 8. Tes prompts ChatGPT

Crée un fichier ou une note :

```text
PROMPTS CV
```

Puis conserve tes prompts préférés.

### Prompt 1 — Améliorer le profil

```text
Voici mes informations :

[INFORMATIONS]

Je recherche un poste de [POSTE].

Améliore mon profil professionnel pour mon CV.

Le résultat doit être :
- professionnel ;
- naturel ;
- court ;
- adapté au poste ;
- fidèle à mon parcours.

N'invente aucune information.
```

### Prompt 2 — Améliorer une expérience

```text
Voici une expérience :

[EXPÉRIENCE]

Transforme-la en description professionnelle pour mon CV.

Utilise des phrases courtes et des verbes d'action.

N'invente aucun résultat ni aucune responsabilité.
```

### Prompt 3 — Analyser une offre

```text
Voici une offre d'emploi :

[OFFRE]

Identifie :
- les missions ;
- les compétences ;
- les qualités ;
- les mots-clés ;
- les exigences importantes.

Compare ensuite ces éléments avec mon profil :

[PROFIL]
```

### Prompt 4 — Corriger le CV

```text
Voici mon CV :

[CV]

Corrige les fautes d'orthographe, de grammaire et les formulations maladroites.

Ne change pas les informations réelles.
N'invente rien.
```

### Prompt 5 — Simuler un recruteur

```text
Agis comme un recruteur.

Voici mon CV :

[CV]

Analyse-le et indique :
- les points forts ;
- les points faibles ;
- les informations manquantes ;
- les éléments inutiles ;
- les améliorations prioritaires.
```

# 9. Tes messages de candidature

Crée également une note :

```text
MESSAGES DE CANDIDATURE
```

Conserve au minimum :

- un message WhatsApp ;
- un modèle d'e-mail ;
- une candidature spontanée ;
- une relance.

Ainsi, tu ne perdras plus de temps à chercher quoi écrire.

---

# 10. Modèle WhatsApp

```text
Bonjour Monsieur/Madame,

Je vous contacte dans le cadre de ma candidature au poste de [POSTE].

Je souhaite vous proposer mon profil, qui correspond aux besoins du poste notamment dans les domaines de [COMPÉTENCES PERTINENTES].

Je vous joins mon CV afin de vous présenter mon parcours plus en détail.

Je reste disponible pour tout échange complémentaire.

Cordialement,

[PRÉNOM NOM]
[TÉLÉPHONE]
```

Adapte toujours le message à la situation.

---

# 11. Modèle d'e-mail

**Objet : Candidature — [POSTE] — [PRÉNOM NOM]**

```text
Bonjour Monsieur/Madame,

Je vous adresse ma candidature au poste de [POSTE].

Mon parcours en [DOMAINE] et mes compétences en [COMPÉTENCES PERTINENTES] correspondent aux principales exigences du poste.

Vous trouverez mon CV en pièce jointe.

Je reste disponible pour tout échange ou entretien.

Cordialement,

[PRÉNOM NOM]
[TÉLÉPHONE]
[ADRESSE E-MAIL]
```

---

# 12. Modèle de candidature spontanée

```text
Objet : Candidature spontanée — [DOMAINE / POSTE]

Bonjour Monsieur/Madame,

Je me permets de vous contacter afin de vous proposer ma candidature spontanée pour une opportunité dans le domaine de [DOMAINE].

Je possède des compétences en [COMPÉTENCES] et j'ai réalisé plusieurs projets dans ce domaine.

Je vous joins mon CV afin de vous présenter mon profil.

Je reste disponible pour tout échange.

Cordialement,

[PRÉNOM NOM]
[TÉLÉPHONE]
```

---

# 13. Modèle de relance

```text
Bonjour Monsieur/Madame,

Je me permets de revenir vers vous concernant ma candidature au poste de [POSTE], envoyée le [DATE].

Je souhaitais savoir si vous aviez eu l'occasion de consulter ma candidature.

Je reste disponible pour tout échange complémentaire.

Cordialement,

[PRÉNOM NOM]
```

# 14. Ton tableau de suivi

Crée un fichier ou tableau appelé :

```text
SUIVI_CANDIDATURES
```

Utilise les colonnes suivantes :

| Date | Entreprise | Poste | Canal | CV utilisé | Statut | Relance | Résultat |
|---|---|---|---|---|---|---|---|
| 10/10 | ABC | Développeur Web | E-mail | CV Web | Envoyée | 15/10 | — |
| 11/10 | XYZ | Assistant IT | WhatsApp | CV IT | En attente | 16/10 | — |
| 12/10 | Digital Pro | Graphiste | E-mail | CV Graphiste | Entretien | — | — |

Ce tableau devient ton **centre de contrôle**.

---

# 15. Ton dossier « Offres »

Ne supprime pas immédiatement les offres auxquelles tu as postulé.

Conserve-les dans :

```text
OFFRES
```

Tu peux créer :

```text
OFFRES
│
├── EN COURS
├── ENVOYÉES
└── TERMINÉES
```

Cela te permet de retrouver rapidement les exigences du poste si le recruteur te contacte.

---

# 16. Ton portfolio

Si ton métier s'y prête, crée également un portfolio.

Cela peut être particulièrement utile pour :

- développeurs ;
- graphistes ;
- photographes ;
- designers ;
- monteurs vidéo ;
- community managers ;
- rédacteurs ;
- freelances.

Ton portfolio peut contenir :

- tes meilleurs projets ;
- des captures ;
- des liens ;
- une courte description ;
- les outils utilisés ;
- ton rôle dans chaque projet.

Ton CV dit :

> **« Je sais faire cela. »**

Ton portfolio peut montrer :

> **« Voici ce que j'ai réellement réalisé. »**

---

# 17. Ton profil LinkedIn

Si tu utilises LinkedIn, vérifie que les informations importantes correspondent à ton CV.

Ton profil peut contenir :

- une photo professionnelle ;
- un titre clair ;
- une présentation ;
- tes compétences ;
- tes expériences ;
- tes projets ;
- ta formation ;
- tes réalisations.

Évite cependant de copier automatiquement tout ton CV dans chaque partie.

Ton profil LinkedIn doit être cohérent avec ton CV, mais peut être plus détaillé.

---

Si nécessaire, crée une adresse réservée aux candidatures.

Exemple :

```text
prenom.nom@gmail.com
```

Utilise-la pour :

- les candidatures ;
- les échanges professionnels ;
- les plateformes d'emploi ;

Cela permet de séparer tes communications personnelles et professionnelles.

# 19. Ton nom de fichier standard

Adopte une règle simple :

```text
CV_Prénom_Nom_Poste.pdf
```

Exemple :

```text
CV_Jean_Dupont_Developpeur_Web.pdf
```

Pour une lettre :

```text
LM_Jean_Dupont_Developpeur_Web.pdf
```

Cette petite habitude donne immédiatement une impression plus professionnelle.

# 21. Mets ton kit à jour

Ton CV n'est pas un document définitif.

Lorsque tu :

- obtiens une nouvelle certification ;
- réalises un nouveau projet ;
- fais un stage ;
- acquiers une nouvelle compétence ;
- obtiens une nouvelle expérience ;

mets ton CV principal à jour.

Ainsi, lorsque tu trouveras une nouvelle opportunité, tu ne partiras jamais de zéro.
