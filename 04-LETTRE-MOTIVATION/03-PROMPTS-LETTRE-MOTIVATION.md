# 1. CRÉER UNE LETTRE DE MOTIVATION

```text
Je veux rédiger une lettre de motivation professionnelle pour le poste de [POSTE].

Voici mes informations :

Nom : [NOM]
Formation : [FORMATION]
Expériences : [EXPÉRIENCES]
Projets : [PROJETS]
Compétences : [COMPÉTENCES]
Certifications : [CERTIFICATIONS]
Qualités : [QUALITÉS]

Voici les informations concernant l’entreprise :

Entreprise : [ENTREPRISE]
Secteur : [SECTEUR]
Poste : [POSTE]
Missions : [MISSIONS]

Rédige une lettre de motivation claire, naturelle, professionnelle et personnalisée.

N’invente aucune information.
N’ajoute aucune expérience, compétence, diplôme ou résultat que je n’ai pas fourni.
La lettre doit idéalement tenir sur une page.
