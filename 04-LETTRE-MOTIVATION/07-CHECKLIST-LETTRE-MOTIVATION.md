# CHECKLIST FINALE — LETTRE DE MOTIVATION

> **Objectif :** vérifier rapidement que ta lettre de motivation est professionnelle, personnalisée, cohérente et prête à être envoyée.

---

# 1. INFORMATIONS PERSONNELLES

- [ ] Mon prénom et mon nom sont correctement écrits.
- [ ] Mon numéro de téléphone est correct.
- [ ] Mon adresse e-mail est correcte.
- [ ] Ma ville est correctement indiquée.
- [ ] Mon adresse LinkedIn est correcte si elle est présente.
- [ ] Mon portfolio est correct si je l’ai ajouté.

---

# 2. DESTINATAIRE

- [ ] Le nom de l’entreprise est correctement écrit.
- [ ] Le nom du recruteur est correct si je le connais.
- [ ] Le poste du destinataire est correct.
- [ ] La ville de l’entreprise est correcte.
- [ ] Je n’ai pas laissé un ancien nom d’entreprise dans la lettre.

---

# 3. OBJET DE LA LETTRE

- [ ] L’objet indique clairement le poste recherché.
- [ ] L’objet correspond à l’offre.
- [ ] La référence de l’offre est indiquée si nécessaire.
- [ ] L’objet est court et professionnel.

### Exemple

**Objet : Candidature au poste de Développeur Web Junior**

---

# 4. INTRODUCTION

- [ ] Je précise le poste recherché.
- [ ] Je précise pourquoi je contacte l’entreprise.
- [ ] Mon introduction est directe.
- [ ] Elle n’est pas trop longue.
- [ ] Elle ne contient pas de phrases inutiles.
- [ ] Elle donne envie de poursuivre la lecture.

---

# 5. MOTIVATION

- [ ] J’explique pourquoi le poste m’intéresse.
- [ ] Ma motivation est liée au poste.
- [ ] Je montre que j’ai compris le besoin de l’entreprise.
- [ ] Je ne me contente pas de dire « je suis très motivé(e) ».
- [ ] Ma motivation paraît naturelle et crédible.

---

# 6. COMPÉTENCES

- [ ] Je présente les compétences pertinentes pour le poste.
- [ ] Je ne liste pas des compétences inutiles.
- [ ] Les compétences indiquées sont réelles.
- [ ] Je ne prétends pas maîtriser un outil que je connais à peine.
- [ ] Les compétences correspondent à celles indiquées dans mon CV.

---

# 7. EXPÉRIENCES

- [ ] Mes expériences sont correctement présentées.
- [ ] Les dates sont correctes.
- [ ] Les intitulés sont corrects.
- [ ] Les missions décrites sont réelles.
- [ ] Je mets en avant les expériences pertinentes.
- [ ] Je n’exagère pas mes responsabilités.
- [ ] Je n’ai rien inventé.

---

# 8. PROJETS

Si je n’ai pas beaucoup d’expérience professionnelle :

- [ ] J’ai valorisé mes projets pertinents.
- [ ] Je précise ce que j’ai réellement réalisé.
- [ ] Je présente les compétences utilisées.
- [ ] Je ne présente pas un projet personnel comme une expérience professionnelle.
- [ ] Je montre ce que le projet démontre sur mes capacités.

---

# 9. FORMATION

- [ ] Mon diplôme ou niveau d’études est correct.
- [ ] Le nom de mon établissement est correct.
- [ ] Les dates sont correctes.
- [ ] Ma spécialité est correctement indiquée.
- [ ] Les informations correspondent à mon CV.

---

# 10. PERSONNALISATION

Une bonne lettre ne doit pas pouvoir être envoyée à n’importe quelle entreprise sans modification.

Vérifie :

- [ ] Le nom de l’entreprise apparaît correctement.
- [ ] Le poste correspond à l’entreprise.
- [ ] Les compétences mises en avant correspondent au poste.
- [ ] Ma motivation est spécifique.
- [ ] J’ai mentionné un élément pertinent concernant l’entreprise lorsque cela est possible.
- [ ] Je n’ai pas simplement remplacé le nom d’une ancienne entreprise.

> **Test simple :** si je peux remplacer le nom de l’entreprise et envoyer exactement la même lettre ailleurs, ma lettre n’est probablement pas assez personnalisée.

---

# 11. COHÉRENCE AVEC LE CV

Compare les deux documents.

- [ ] Les dates correspondent.
- [ ] Les formations correspondent.
- [ ] Les expériences correspondent.
- [ ] Les intitulés de poste correspondent.
- [ ] Les compétences correspondent.
- [ ] Les projets correspondent.
- [ ] Les technologies correspondent.
- [ ] Les informations personnelles correspondent.

### Attention

Une contradiction entre le CV et la lettre peut réduire la crédibilité de la candidature.

---

# 12. HONNÊTETÉ

Pose-toi cette question :

> **Est-ce que tout ce que j’ai écrit est vrai ?**

- [ ] Je n’ai inventé aucune expérience.
- [ ] Je n’ai inventé aucun diplôme.
- [ ] Je n’ai inventé aucune certification.
- [ ] Je n’ai inventé aucun résultat.
- [ ] Je n’ai inventé aucun chiffre.
- [ ] Je n’ai pas exagéré mon niveau.
- [ ] Je n’ai pas présenté une compétence comme une expertise si ce n’est pas le cas.

---

# 13. STRUCTURE

- [ ] La lettre possède une introduction claire.
- [ ] Les paragraphes sont bien organisés.
- [ ] Chaque paragraphe a un objectif.
- [ ] Il n’y a pas de répétitions importantes.
- [ ] La conclusion est claire.
- [ ] La lettre tient idéalement sur une page.

### Structure recommandée

**Pourquoi ce poste ?**

↓

**Pourquoi mon profil correspond ?**

↓

**Pourquoi cette entreprise ?**

↓

**Proposition d’entretien**

---

# 14. STYLE

- [ ] Le ton est professionnel.
- [ ] Le ton reste naturel.
- [ ] Les phrases sont compréhensibles.
- [ ] Les phrases ne sont pas inutilement longues.
- [ ] Je n’utilise pas trop de mots compliqués.
- [ ] Je n’utilise pas de phrases exagérées.
- [ ] Je n’utilise pas trop de répétitions.
- [ ] La lettre ressemble à ma façon professionnelle de m’exprimer.

---

# 15. ORTHOGRAPHE ET GRAMMAIRE

Vérifie :

- [ ] Les fautes d’orthographe.
- [ ] Les accords.
- [ ] La conjugaison.
- [ ] Les majuscules.
- [ ] La ponctuation.
- [ ] Les espaces.
- [ ] Les accents.
- [ ] Les noms propres.

Relis la lettre au moins une fois avant de l’envoyer.

---

# 16. MISE EN PAGE

- [ ] La lettre est propre visuellement.
- [ ] La police est facile à lire.
- [ ] La taille du texte est confortable.
- [ ] Les paragraphes sont suffisamment espacés.
- [ ] Les marges sont correctes.
- [ ] L’ensemble tient sur une page si possible.
- [ ] La présentation reste sobre.
- [ ] Les couleurs sont limitées.
- [ ] Il n’y a pas d’éléments graphiques inutiles.

---

# 17. FORMAT PDF

Avant l’envoi :

- [ ] J’ai exporté la lettre en PDF.
- [ ] J’ai ouvert le PDF après exportation.
- [ ] La mise en page n’a pas bougé.
- [ ] Aucun texte n’est coupé.
- [ ] Aucun élément n’est décalé.
- [ ] Les caractères sont correctement affichés.
- [ ] Le document est lisible sur téléphone.
- [ ] Le document est lisible sur ordinateur.

---

---

# 19. AVANT UN ENVOI PAR E-MAIL

- [ ] L’adresse du destinataire est correcte.
- [ ] L’objet du mail est clair.
- [ ] Le message d’accompagnement est professionnel.
- [ ] Le CV est joint.
- [ ] La lettre est jointe.
- [ ] Les bons fichiers sont joints.
- [ ] Les fichiers sont lisibles.
- [ ] Les noms des fichiers sont professionnels.
- [ ] Je n’ai pas oublié une pièce demandée.

---

# 20. AVANT UN ENVOI PAR WHATSAPP

Si l’entreprise accepte les candidatures par WhatsApp :

- [ ] Je contacte le bon numéro.
- [ ] Mon message est professionnel.
- [ ] Je précise le poste recherché.
- [ ] Je joins mon CV.
- [ ] Je joins ma lettre si elle est demandée.
- [ ] Les fichiers sont en PDF.
- [ ] Je n’envoie pas plusieurs messages inutiles.
- [ ] Je reste disponible pour répondre.

---

# 21. TEST DES 10 SECONDES

Imagine que le recruteur regarde ta lettre pendant seulement quelques secondes.

Peut-il comprendre rapidement :

- [ ] Qui je suis ?
- [ ] Quel poste je recherche ?
- [ ] Pourquoi je postule ?
- [ ] Quelles sont mes principales compétences ?
- [ ] Pourquoi cette entreprise ?
- [ ] Comment me contacter ?

Si la réponse est oui, ta lettre est claire.

---

# 22. TEST DU RECRUTEUR

Lis ta lettre et demande-toi :

> **Pourquoi le recruteur devrait-il continuer à lire mon CV après cette lettre ?**

Si tu ne trouves aucune réponse claire, améliore :

- ta proposition de valeur ;
- la personnalisation ;
- les compétences pertinentes ;
- tes réalisations ;
- ta conclusion.

---

# 23. TEST DE PERSONNALISATION

Pose-toi ces trois questions :

### Question 1

**Pourquoi cette entreprise ?**

Ma réponse :

> [RÉPONSE]

### Question 2

**Pourquoi ce poste ?**

Ma réponse :

> [RÉPONSE]

### Question 3

**Pourquoi moi ?**

Ma réponse :

> [RÉPONSE]

Si tu ne peux pas répondre clairement aux trois questions, ta lettre doit être améliorée.

---

# 24. TEST DE VÉRITÉ

Pour chaque information importante, demande-toi :

> **Puis-je prouver ce que je viens d’écrire ?**

Si oui :

**Je conserve.**

Si non :

**Je vérifie ou je supprime.**

Cette règle permet d’éviter les informations inventées ou exagérées.

# 28. À RETENIR

Une bonne lettre de motivation doit être :

**CLAIRE**

Le recruteur comprend rapidement ta candidature.

**PERSONNALISÉE**

Elle correspond réellement à l’entreprise et au poste.

**CRÉDIBLE**

Elle présente uniquement des informations vraies.

**PERTINENTE**

Elle met en avant les éléments utiles pour le poste.

**PROFESSIONNELLE**

Elle est bien écrite et correctement présentée.

> **Une lettre de motivation parfaite n’est pas celle qui contient le plus de mots.**

> **C’est celle qui permet au recruteur de comprendre rapidement pourquoi ton profil mérite d’être examiné.**

Si la réponse est oui, vérifie une dernière fois les informations et envoie ta candidature.

**Prépare. Personnalise. Vérifie. Envoie.**
