# PROMPTS CHATGPT
## Préparer ton entretien d'embauche

### Comment utiliser ces prompts

Avant ton entretien, donne à ChatGPT :

- ton CV ;
- l'offre d'emploi ;
- le nom du poste ;
- les informations que tu connais sur l'entreprise ;
- ton niveau d'expérience.

ChatGPT peut ensuite t'aider à simuler l'entretien, préparer tes réponses et identifier les questions auxquelles tu dois te préparer.

> **Important :** n'apprends pas des réponses par cœur. Utilise les réponses générées comme préparation et réponds naturellement pendant l'entretien.

# PROMPT 01 — SIMULER UN ENTRETIEN

```text id="a7k3qp"

Je vais passer un entretien pour :

Poste : [POSTE]
Entreprise : [ENTREPRISE]

Voici mon CV :

[COLLER MON CV]

Voici l'offre :

[COLLER L'OFFRE]

Simule un véritable entretien d'embauche avec moi.

Pose-moi une seule question à la fois.

Attends ma réponse avant de continuer.

Après chaque réponse :
- évalue ma réponse ;
- indique ce qui est bien ;
- indique ce qui peut être amélioré ;
- donne-moi une meilleure approche si nécessaire.

Ne me donne pas la réponse avant que j'aie répondu.
```

**Analyse après entretien**

---

## RÈGLE D'OR

Ne mémorise pas des réponses mot pour mot.

Le recruteur cherche à discuter avec toi, pas à écouter un texte récité.

Prépare plutôt :

- tes idées principales ;
- tes exemples ;
- tes compétences ;
- tes réalisations ;
- tes motivations ;
- quelques réponses difficiles.

**Prépare tes réponses. Mais reste naturel pendant l'entretien.**
