# PROMPTS CHATGPT
## Messages, e-mails, lettres et relances

### Comment utiliser ces prompts

Ces prompts t'aident à préparer les différentes communications qui accompagnent ton CV.

Avant d'envoyer un message :

- vérifie le nom de l'entreprise ;
- vérifie le nom du poste ;
- vérifie tes coordonnées ;
- vérifie que ton CV est bien joint ;
- adapte le message à la situation ;
- relis toujours le résultat de ChatGPT.

> **Règle importante :** un bon message doit être court, professionnel et personnalisé. Évite d'envoyer exactement le même message à toutes les entreprises.

# RÈGLE D'OR

Un message de candidature n'a pas besoin d'être long.

Il doit surtout être :

**Clair + Personnalisé + Professionnel + Concis**

Évite les messages comme :

> "Bonjour, je cherche un emploi. Voici mon CV."

Prends quelques secondes pour expliquer **pour quel poste tu écris et pourquoi ton profil est pertinent**.

Une petite personnalisation peut faire une grande différence.
