# PROMPTS CHATGPT
## Création et amélioration de ton CV

### Comment utiliser ces prompts

1. Ouvre ChatGPT sur ton téléphone.
2. Copie le prompt qui correspond à ton besoin.
3. Remplace les informations entre `[ ]`.
4. Colle le prompt dans ChatGPT.
5. Réponds aux questions supplémentaires si ChatGPT t'en pose.
6. Vérifie toujours les informations générées avant de les utiliser.

> **Important :** ChatGPT doit t'aider à présenter ton expérience, pas à inventer des informations. Ne présente jamais comme vraie une expérience, une compétence, un diplôme ou une certification que tu n'as pas.

---

# PROMPT 01 — CRÉER MON PROFIL PROFESSIONNEL

```text
Agis comme un recruteur expérimenté et un spécialiste des CV.

Je veux rédiger mon profil professionnel.

Voici mes informations :

Nom : [Prénom Nom]
Situation : [étudiant / jeune diplômé / professionnel / en recherche d'emploi]
Domaine : [domaine]
Poste recherché : [poste]
Formation : [formation]
Compétences principales : [compétences]
Expériences : [expériences]
Projets : [projets]
Objectif professionnel : [objectif]

Rédige un profil professionnel de 3 à 5 lignes pour mon CV.

Le texte doit être :
- professionnel ;
- naturel ;
- précis ;
- crédible ;
- adapté à mon niveau d'expérience ;
- orienté vers la valeur que je peux apporter à une entreprise.

Évite les phrases génériques et les exagérations.

Donne-moi 3 versions différentes.
```

# PROMPT 03 — CRÉER LE TITRE DE MON CV


# PROMPT 12 — PRÉPARER MON CV POUR UN RECRUTEUR

```text
Agis comme un recruteur qui reçoit beaucoup de CV.

[COLLER LE CV]
```

# PROMPT 13 — TEST DES 10 SECONDES

```text
Agis comme un recruteur.

Je vais te donner mon CV :

[COLLER LE CV]

Imagine que tu n'as que 10 secondes pour le parcourir.

Dis-moi immédiatement :
- mon métier ;
- mon niveau ;
- le type de poste que je recherche ;
- mes 3 principales compétences ;
- mon principal point fort ;
- ce qui n'est pas suffisamment clair.

Si tu n'arrives pas à identifier une information rapidement, indique-le.

Puis donne-moi les modifications nécessaires pour rendre mon CV plus lisible.
```

```text

Évalue les éléments suivants sur 10 :

- Clarté
- Lisibilité

- Pertinence
- Profil
- Compétences
- Expériences
- Projets
- Formation
- Adaptation au poste

4. ce que je dois vérifier avant d'envoyer le CV.

Ne modifie aucune information sans me demander confirmation.
```

# CONSEIL FINAL

Ne demande pas à ChatGPT de "rendre ton CV impressionnant" en lui donnant seulement ton nom et le poste recherché.

Plus tu lui donnes **d'informations réelles et précises**, plus les résultats seront utiles.

La meilleure méthode est :

**Tes informations → ChatGPT → amélioration → vérification → adaptation → CV final**

Et rappelle-toi :

> **ChatGPT peut améliorer la présentation de ton parcours. Il ne doit jamais inventer ton parcours.**
