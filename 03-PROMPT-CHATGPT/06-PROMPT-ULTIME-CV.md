# PROMPT ULTIME
## Construire et optimiser une candidature complète avec ChatGPT

### À quoi sert ce prompt ?

Ce prompt permet d'utiliser ChatGPT comme **assistant de candidature**.

Il peut t'aider à :

- analyser ton profil ;
- analyser une offre d'emploi ;
- identifier tes compétences pertinentes ;
- améliorer ton CV ;
- adapter ton CV à l'offre ;
- préparer ton message de candidature ;
- préparer ton entretien ;
- vérifier ta candidature avant l'envoi.

> **Important :** ce prompt ne doit jamais servir à inventer une expérience, un diplôme, une compétence ou un résultat.

---

# COMMENT UTILISER CE PROMPT

Tu n'es pas obligé de remplir toutes les informations en une seule fois.

Tu peux commencer avec :

**Ton profil + ton CV + l'offre d'emploi.**

ChatGPT pourra ensuite te demander les informations manquantes.

### Exemple

```text
Mon poste recherché :
Développeur Web Junior

Mon expérience :
6 mois de stage

Mes compétences :
HTML, CSS, JavaScript, React, Laravel

Mon projet :
Création d'une plateforme de gestion scolaire

Voici l'offre :

[COLLER L'OFFRE]
```

Puis tu ajoutes le prompt ultime.

## ATTENTION

Ce prompt est puissant, mais **ChatGPT ne connaît pas automatiquement ton parcours réel**.

La qualité du résultat dépend des informations que tu lui donnes.

Plus tes informations sont précises, plus les recommandations seront pertinentes.

Et avant d'envoyer ta candidature, **relis toujours le résultat généré par ChatGPT**.

Ton CV doit rester entièrement fidèle à ton parcours réel.
